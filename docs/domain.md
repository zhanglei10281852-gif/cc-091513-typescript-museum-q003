# 领域说明

科研取样可能永久消耗标本材料，因此申请质量、取样位置、审批结论和实际损耗必须分别记录。送审后的版本变化、委员回避和成果返还期限都会影响当前状态。

`reference/domain.json` 保存公开的申请状态、取样方法和成果状态枚举。正式业务记录使用稳定标识，并保留标本余量、审批版本和损耗记录。

## 核心不变量

1. **余量只由实物记录决定。** 每个分区的实物余量 = 建档初始质量 − Σ 切割记录的实际质量；纸面审批不能修改它。可预占量再扣除生效中的预留（`held`）。
2. **预留即互斥。** 送审且评审路径激活时，按预计质量创建 `held` 预留。所有写操作在进程内互斥区完成，“读余量 → 判定 → 落预留”是原子的，并发申请不可能预占同一份材料。
3. **预留释放时机受限。** 只在以下情况释放：委员会/独任/主任拒绝、审批 SLA 超时、申请人撤回、送审后修订使旧版本失效（superseded）、批准有效期届满未取样。批准后的取样由切割记录结算（`consumed`）。
4. **送审后关键参数不可原地修改。** 研究目的、取样位置（分区/说明）、预计质量、检测方法、成果承诺、保密期限中任一变化都产生新版本；旧版本冻结为 `superseded`，其预留释放，新版本回到草稿态重新送审。送审前的修改就地更新草稿。
5. **批准结论不可修改。** 实际取样与批准量有偏差时，只追加切割记录与偏差判定（差值、百分比、是否在容忍度内、方法是否一致），并重算余量；批准量、批准编号、表决快照原样保留。

## 评审路径（规则版本 1.0.0，见 `src/domain/rules.ts`）

按当前规则版本生成路径，版本号随每次表决、决定、偏差记录落档：

- **独任初审**：已加固区且预计质量 ≤ 500mg。
- **委员会评审**：未加固区，或预计质量 > 500mg；满 3 名无回避委员成会，满 3 票即结算，赞成严格多于反对才通过（平票从紧）。主任不进入委员会池。
- **主任签批**：取样后分区实物余量将低于安全库存 200mg 时追加。
- **回避**：委员与申请人在指定冲突名单中、或与申请人同单位、或其单位冲突名单命中申请单位，均移出表决池。回避后人数不足时路径为 `blocked_recusal`，**不预占材料**；管理员增补委员后重建路径并补做预留。
- **补件**：委员可投 `request_changes` 并指明字段，申请回到“等待补件”，研究员回应后该轮继续；有未结补件项时不能送审。
- **时限**：审批 SLA 14 天，超时自动拒绝并释放预留；批准有效期 90 天，逾期未取样仅释放预留，批准结论保留但不可再取样。
- **成果返还**：批准时按承诺日期建立返还义务，到期前 7 天为 `due`，逾期为 `overdue`，管理员登记接收后为 `received`。

## 角色与视图

- 研究员：创建/修订/撤回本人申请、送审、回应补件、查看本人进度与补件项。
- 委员：查看轮到自己且无回避关系的待办、投票、要求补件、触发超时巡检。
- 管理员：维护标本分区与委员名册、重建被回避阻塞的路径、登记实际切割与成果接收、从剩余质量追溯全部决定/版本/切割/预留/成果状态及每条记录采用的规则版本。

## 状态与持久化

运行时状态（标本、委员、申请、版本、预留、切割、计数器）与不可变事件流保存在内存中，优雅退出时写入 `STATE_FILE`（默认 `.runtime/state.json`），启动时回放恢复。事件流记录每个写操作的操作者、时间与类型，供审计。
