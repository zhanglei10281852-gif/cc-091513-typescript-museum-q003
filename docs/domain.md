# 领域说明

科研取样可能永久消耗标本材料，因此申请质量、取样位置、审批结论和实际损耗必须分别记录。送审后的版本变化、委员回避和成果返还期限都会影响当前状态。

`reference/domain.json` 保存公开的申请状态、取样方法和成果状态枚举。`reference/seed.json` 保存初始用户、标本与回避关系。正式业务记录写入 `.runtime/state.json`（可用 `SAMPLING_STATE_FILE` 覆盖）。

## 核心不变量

1. **余量公式**：`可用余量 = 初始质量 - 历次实际切割消耗 - 在途预占`。
   - 送审且通过额度校验后即预占（reviewing）；批准未取样期间继续预占。
   - 预占只在 **拒绝、评审超时、撤回** 时释放；批准后取样则转为实际消耗。
   - 所有消耗都来自不可变的切割记录，可从余量反向追溯。
2. **并发互斥**：所有状态变更经同一把进程内互斥队列串行执行，两个并发申请不可能同时通过同一份材料的额度校验。
3. **版本不可变**：送审后修改目的/位置/质量/方法/返还承诺/保密期任一关键参数，生成新版本；旧版本标记 `superseded`，旧步骤关闭，决定与事件保留。
4. **规则版本锁定**：每个申请版本在创建时锁定当时规则版本，步骤、决定、切割都记录所采用的规则版本；规则升级不影响在途版本。
5. **批准结论不可改**：实际取样量与批准量有偏差时只追加 `DeviationRecord` 并重算余量，申请仍保持 approved；同一申请只能登记一次切割。
6. **回避**：委员与申请人同机构自动回避，另有显式回避关系（针对申请人或机构）。无需回避的委员不足法定人数时，申请挂起为 submitted 且**不预占额度**，补员后管理员可重新路由。

## 审批路径（由规则路由）

| 情形 | 路径 |
| --- | --- |
| 加固区且质量 < 500mg | 单委员 |
| 加固区且质量 ≥ 500mg | 三人委员会多数通过 + 主任签批 |
| 未加固区（任意质量） | 三人委员会全票通过 + 主任签批 |
| 未加固区 + 破坏性等级 > 2（micro_drill/section） | 系统直接驳回，不预占 |
| 单次申请 > 标本可用余量 50% | 配额驳回 |
| 未加固区申请 > 可用余量 25% 或超过分区余量 | 配额驳回 |

评审截止 72 小时（`reviewTimeoutHours`），超时系统驳回并释放额度。

## 成果状态

切割登记后承诺开始计时：not_due → due（到期前 7 天起）→ overdue；登记返还后 received。

## 主要事件流

`draft_created → submitted → (supplement_requested → supplement_submitted → supplement_accepted)? → decision_recorded* → approved/rejected/review_timed_out/withdrawn → cutting_recorded (+deviation) → result_received`；改版本插入 `amended/rerouted`，无法定人数插入 `routing_blocked`。

事件仅追加（`seq` 单调递增），管理员追溯视图按申请聚合全部事件、决定、切割、偏差与规则版本。
